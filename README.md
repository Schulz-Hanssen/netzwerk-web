# Netzwerk – Web-App (Vorschau)

Dieses Repository enthält nur die **fertig gebaute** Desktop-Web-App aus dem privaten Projekt `netzwerk-app`, bereitgestellt über GitHub Pages.

- Enthält keinen Quellcode-Verlauf und **keine persönlichen Daten**. Kontaktdaten liegen ausschließlich Ende-zu-Ende-verschlüsselt auf den Geräten des Nutzers.
- Phase 0: nur erfundene Testdaten verwenden.
